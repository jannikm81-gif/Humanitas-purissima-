# Security Policy & Invarianten-Härtung

## Abgedecktes Bedrohungsmodell (In-Scope)
- **Zensur & Manipulation:** Schutz von Sensornetzwerken durch Entropie-Decay via KL-Divergenz ($D_{KL}$).
- **Physische Erpressung:** Ununterscheidbarkeit von Duress-Keys via DKDP (HKDF-SHA256).
- **Sybil-Angriffe:** Schutz von Gemeinschaftsmitteln durch Pairwise Bounded Quadratic Funding.

## Meldung von Schwachstellen
Bitte erstelle ein **Invarianten-Audit Issue** über das vorgefertigte Template im Repository oder kontaktiere das Core-Team direkt.
